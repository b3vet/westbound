# M1 playtest: Road and look

**Gate (spec M1):** an empty-road 20-minute drive holds 60 fps with no thermal throttling on an iPhone 13-class device at Medium, and the game looks right across the whole color script on both renderers.

**Build:** the start scene is `src/dev/road_drive.tscn`. A placeholder red box auto-drives the procedural farmland highway.

| Control | Phone | Desktop |
| --- | --- | --- |
| Change lane | Tap the left edge (upper = left, lower = right) | ← / → |
| Speed + / − (100, 160, 200, 250, 280 km/h) | Tap the right edge (upper = faster, lower = slower) | ↑ / ↓ |
| Cycle camera (chase, far, hood, high) | Tap the upper-right quarter | C |
| Dev HUD | Three-finger tap | backtick |
| Time of day | Drag the bottom `sky_t` slider; **play** runs the whole day in 40 s | same |
