# Westbound display-name profanity list (English + Turkish). Kept small on purpose:
# it catches the obvious slurs and obscenities, not every insult. Moderators handle
# the rest with `westbound-server admin rename` (docs/SERVER.md → "Admin CLI").
#
# Used by crates/server/src/profanity.rs, compiled into the binary. Entries are
# normalized the same way as names: lowercased, Turkish letters folded (ç→c, ğ→g,
# ı/İ→i, ö→o, ş→s, ü→u), leetspeak mapped (0→o 1→i/l 3→e 4→a 5→s 7→t @→a $→s …),
# separators dropped, and every letter may repeat ("fuuuck").
#
#   word     banned anywhere in the name ("xXwordXx", "w.o.r.d", "W0rd")
#   =word    banned only as a whole word of the name: short words that hide inside
#            ordinary ones ("=ass" rejects "Ass Man" and "BigAss", not "Classic")
#   !word    allowed: a banned match lying wholly inside this word is ignored
#            (the Scunthorpe problem)
#
# One entry per line, letters only (no digits). Changing this file changes which
# new names are accepted; existing names are not re-checked.
